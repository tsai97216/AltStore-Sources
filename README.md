## How it works

This repository handles the boring part automatically:

1. Check upstream projects and configured sources.
2. Detect new IPA releases.
3. Update the source metadata.
4. Run validation and compatibility checks.
5. Commit the generated changes.
6. Publish the source through GitHub Pages.

The source itself is generated from the repository data, so you normally only need the source URL above.
